# Olis

Проект **Olis** — это веб-сайт, разработанный в рамках учебной программы YtYt. Данный проект представляет собой адаптивный лендинг с акцентом на чистый код и современный дизайн.

---

## 🛠 Технологии

* **HTML5** — семантическая структура документа.
* **CSS3** — адаптивная верстка с использованием современных подходов.
* **Tailwind CSS** — для быстрой и гибкой стилизации компонентов.
* **Git** — система контроля версий для отслеживания изменений.

---

## 🚀 Основные возможности

* **Адаптивность:** Полная поддержка мобильных устройств с оптимизацией контента под ширину **510px**.
* **Минимализм:** Использование упрощенных структур без избыточного кода, что обеспечивает легкую поддержку и чтение проекта.
* **Семантика:** Правильная иерархия элементов для лучшей индексации и читаемости.

## 💡 Как запустить проект

1. Клонируйте репозиторий:
`git clone <ссылка-на-ваш-репозиторий>`
2. Откройте файл `index.html` в вашем браузере.
3. Для внесения изменений используйте любой редактор кода (например, VS Code).
